# 自动起始面数预算验证（2026-09-25）

公开生成入口不再直接沿用约512面的历史基线。默认起始目标为 `max(512, 历史基线实际面数, ceil(源三角面数/2))`，实际面数上限默认8192，支持显式覆盖。它是避免过度简化的工程起点，不是最优面数或保真误差界。

基线最多三次生成及数量校正，接受目标±10%内且不超过上限的严格有效输出。随后在新基线尺度重新测量缺陷，使用对应UV和梳理方向场筛选约束，并进入完整v5。最终推荐不能低于起始目标90%；生成不到合格基线时不导出旧低面数回退。后续尺寸需求及恢复仍可提高面数。
